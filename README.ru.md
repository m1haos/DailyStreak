# DailyStreak

Ежедневные награды за вход для серверов на Paper. Игрок открывает календарь командой `/daily`, забирает по одной награде в день и набирает серию. Пропустил день — серия начинается заново.

[English version](README.md)

## Возможности

- Календарь до 28 дней, у каждого дня свой значок и любой набор наград: предметы, деньги, консольные команды
- День меняется для всех одновременно: часовой пояс и время сброса задаются в конфиге
- Дни поблажки: можно разрешить пропустить день без потери серии
- После последнего дня календарь начинается сначала или каждый день выдаёт награду последнего дня
- Предметы, которые не влезли в инвентарь, падают под ноги игроку
- SQLite без настройки, MySQL и MariaDB для сетей серверов
- Плейсхолдеры PlaceholderAPI, деньги через Vault; оба необязательны
- Сообщения на русском и английском, все редактируются, форматирование MiniMessage

## Установка

1. Положите `DailyStreak.jar` в `plugins/`.
2. Запустите сервер. В `plugins/DailyStreak/` появятся `config.yml`, `rewards.yml` и `lang/`.
3. Настройте награды и часовой пояс, выполните `/daily reload`.

Для русских сообщений поставьте в `config.yml` значение `language: ru`.

Библиотеки для базы данных (HikariCP, драйверы SQLite и MariaDB) Paper скачает сам при первом запуске.

## Команды и права

| Команда | Право | По умолчанию | Что делает |
|---|---|---|---|
| `/daily` | `dailystreak.command.daily` | все | Открыть календарь |
| `/daily reload` | `dailystreak.command.reload` | op | Перезагрузить конфиг, награды и сообщения |
| `/daily reset <игрок>` | `dailystreak.command.reset` | op | Сбросить серию игрока, в сети он или нет |

`dailystreak.admin` включает оба админских права.

## Награды

Календарь лежит в `rewards.yml`, по записи на день:

```yaml
days:
  - icon: diamond
    rewards:
      - type: item
        material: diamond
        amount: 3
      - type: money
        amount: 500
      - type: command
        command: "lp user <player> permission settemp kits.vip true 1d"
        description: "<gold>VIP-набор на сутки"
```

`description` — строка, которую игрок видит в меню для награды-команды. Без неё команда всё равно выполнится, но в списке наград её не будет.

## Плейсхолдеры

Если установлен PlaceholderAPI:

| Плейсхолдер | Значение |
|---|---|
| `%dailystreak_streak%` | Дней подряд с учётом сегодняшней награды |
| `%dailystreak_day%` | День календаря, который забран сегодня или будет забран |
| `%dailystreak_total%` | Всего полученных наград |
| `%dailystreak_available%` | `true`, если сегодняшняя награда ещё ждёт |
| `%dailystreak_next%` | Время до следующего дня, например `5 ч 12 мин` |

## Требования

- Paper 26.2
- Java 25
- Vault и плагин экономики — только для денежных наград
- PlaceholderAPI — только для плейсхолдеров

## Сборка

```
./gradlew build
```

Jar появится в `build/libs/`. `./gradlew runServer` запускает тестовый сервер с плагином.
